# J mark

Jethro's logo (chosen 2026-11-03), vectorised from his PNG with the logo-vector skill's first rung: an
11-corner polygon measured from the image. Overlap with the source: IoU 0.9985. A 1 px grey seam inside
the stem of the source PNG was an artefact of the image and is left out.

- `j-mark.svg`, `j-mark-white.svg`: the mark alone (463 x 457)
- `j-icon.svg`: the app icon, white mark on a #111111 rounded square (also `app/icon.svg`)
- `j-icon-512.png`, `app/apple-icon.png` (180 px): rendered from `j-icon.svg`
- In code: `components/logo-mark.tsx` draws it in `currentColor`
